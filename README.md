# R-proy1
# compilacion:
para compilar simplemente colocarse en el directorio del proyecto y escribir "make"

# ejecutar cliente
escribir ./cliente <ip> <puerto>, donde "ip" es la ip del servidor (tambien se puede como nombre de dominio) 

# ejecutar servidor
escribir ./servidor. Se colocaran valores por defecto si solo se escribe el comando, estos son: puerto: 5000, puerto HTTP 8080, nombre de la carpeta buzon: ./buzones.

se puede cambiar esos valores con las vanderas -c <perto>, -h <puerto>, -b <directorio> respectivamente
